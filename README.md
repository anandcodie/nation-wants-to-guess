# Nation Wants to Guess (hosted copy)

Built pages from `nation-wants-to-guess-v2`, served by GitHub Pages.

- `index.html` is `player.html`: the player page (room code, then team pick).
- `quiz.html` is the full page: TV view and Host remote.

To refresh after editing the quiz: in `nation-wants-to-guess-v2` run `python server.py --build`,
copy `player.html` here as `index.html` and `quiz.html` as `quiz.html`, then commit and push.
